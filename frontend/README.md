# Demo UI - Edutap Image API

> A simple UI to demonstrate the usage of Edutap Image API

## Installation

1. Activate the correct node version using nvm
```bash
nvm use
```

2. Enable pnpm package manager
```bash
corepack enable
```

3. Install the dependencies
```bash
pnpm install
```

## Running the app

```bash
pnpm dev
```
